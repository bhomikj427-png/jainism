# chapters/hindu/devotional/

**Devotional / mythological / iconographic** Hindu chapters land here — deities, vāhanas,
iconography, bhakti, the Trimūrti and the Śaiva/Vaiṣṇava/Śākta deity-families.

Sibling sub-folders under `hindu/`:
- `darsana/` — the philosophical systems (the āstika darśanas: Vedānta, Sāṃkhya, Yoga, Nyāya, Vaiśeṣika, Mīmāṃsā).
- `scripture/` — the epics and canonical texts (Vedas, Upaniṣads, Mahābhārata, Rāmāyaṇa, Gītā, the root sūtras).

This split exists because "Hindu" spans genuinely different domains (philosophy vs deity vs text);
keeping them in one flat folder would not scale. See `chapters/INDEX.md` for the live chapter map.
